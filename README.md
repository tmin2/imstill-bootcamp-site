# 나는아직 런칭 부트캠프 (imstill-bootcamp)

> **공식 웹사이트**: [https://tmin2.github.io/imstill-bootcamp/](https://tmin2.github.io/imstill-bootcamp/)

AI 기반 5주 완성 브랜드 런칭 부트캠프 "나는아직"의 공식 웹사이트입니다.

## ✨ 주요 기능 및 특징
- **1~5강 단일 페이지 애플리케이션 (SPA)**: 상단 고정 네비게이션으로 매끄러운 탭 전환
- **강의별 리틀리(Littly) 수강권 구매 링크 연동**: 각 강의 상단 전용 CTA 버튼
- **카카오톡 1:1 상담 플로팅 버튼**: 부드러운 바운스 모션 및 실시간 상담 연결
- **인터랙티브 모션 & 마이크로 애니메이션**:
  - 1~5강 강의 카드 마우스 호버 시 **오렌지 네온 테두리 발광(Border Glow)** 효과
  - 히어로 그래픽 스티커 둥둥 플로팅 효과
  - 수강 신청 CTA 버튼 펄스 효과
  - 부트캠프 5주 파이프라인 카드 입체 리프트 효과
- **완전 반응형 웹**: 모바일 및 데스크톱 디바이스 완벽 지원
